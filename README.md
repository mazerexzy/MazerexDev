Я Марк, фуллстек разработчик, делаю сайты и телеграм ботов. Сайт собран как одна большая 3D сцена: планета на фоне, у каждой секции свои эффекты, а на странице отзывов падают метеориты и под курсором трескается земля.

Что есть:

- 3D фон на three.js через react-three-fiber
- лайт режим для слабых устройств, без тяжёлой сцены
- фоновая музыка по всему сайту, выключается одной кнопкой
- русский и английский язык
- страница отзывов
- адаптив под телефоны

## Запуск

```
npm install
npm run dev
```

Сборка `npm run build`. Основной деплой на Vercel, ещё собирается под GitHub Pages и Cloudflare Pages.
